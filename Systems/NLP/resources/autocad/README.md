# AutoCAD contract resources

This directory contains only the machine-readable metadata contract for plan-block
observations. It intentionally contains no DWG, DXF, DWT, geometry, symbols, or
canonical graphical block definitions.

`block_contract.json` is a packaged representation of the approved product rules in
`20_AUTOCAD_BLOCK_CONTRACT.md`, `22_CABLE_LENGTHS_AND_CONDUITS.md`,
`24_AV_CABLE_SYSTEM.md` and `25_DWG_SYNCHRONIZATION.md`. Product documents remain
authoritative.
