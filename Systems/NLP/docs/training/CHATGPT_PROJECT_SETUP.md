# Как запустить своего ChatGPT-помощника по чертежам NEIROLINKS

Проектировщик использует **свой ChatGPT**, без доступа к вашему аккаунту, вашим перепискам, контроллерам или исходникам разработки.

## Надёжный старт: ChatGPT Project с двумя текстовыми файлами

1. Создать **новый Project** в своём ChatGPT, например `NEIROLINKS · Чертежи AutoCAD`.
2. Скачать файл [PROJECT_KNOWLEDGE.txt](PROJECT_KNOWLEDGE.txt) из этого каталога и добавить его в **источники проекта**. Это компактная база знаний по начальному проектированию освещения, с нормами и ссылками.
3. Открыть настройки этого Project и вставить текст файла [PROJECT_INSTRUCTIONS.txt](PROJECT_INSTRUCTIONS.txt) в **Project instructions**.
4. Начать чат: «Я готовлю чертёж освещения в AutoCAD для NL Project 3.0. Помогай по справочнику и указывай источник для каждого правила».
5. По ходу работы задавать конкретные вопросы. Для ошибки на чертеже приложить скриншот свойств блока (его точное имя, список атрибутов, текущие значения). Не загружать несогласованные данные заказчиков.

**Ограничение:** загруженный файл — снимок текущей редакции. Когда справочник обновлён, его надо заново загрузить в Project. База знаний содержит примеры и базовые правила, **не все 71 Exact ATTDEF sets**. Для остальных блоков нужны дополнительные канонические документы.

## Дополнение: подключить GitHub на чтение, если доступно

1. В **Settings → Plugins/Apps → GitHub** проверить, есть ли подключение GitHub у конкретного пользователя и поддерживается ли оно в доступном режиме ChatGPT.
2. Если приложение доступно, авторизовать **свой** GitHub и дать доступ к соответствующему репозиторию, если он доступен для выбора. Это не гарантируется самим фактом публичной ссылки: доступ через GitHub-приложение зависит от плана, аккаунта и разрешений GitHub.
3. В чате указывать точный путь: `psv76/Neirolinks → Systems/NLP/docs/training/` и для проверки деталей `Systems/NLP/docs/autocad/`. Нужен именно **принятый main**, а не случайная рабочая ветка.
4. Подключённый ChatGPT может **запрашивать** разрешённое содержимое репозитория, но это **не непрерывная синхронизация** и не замена ответственности проектировщика за готовый DWG.

Если GitHub-приложение недоступно, первая схема с двумя текстовыми файлами остаётся рабочей. Для неизвестных атрибутов можно отдельно добавлять в ChatGPT источники, скачанные по ссылкам, или задавать вопросы ответственному проектировщику.

## Готовые вопросы

- «Какой canonical block взять для встроенного светильника 230 В?»
- «Что заполнить в `LIGHT_IN_230V`? Дай точный набор ATTDEF и ссылку на норму».
- «Почему у `SW_IN_2` нет `CABLE_SOURCE`?»
- «Светильники `111.01` и `111.02`: как связать в одну линию? Это учебный пример».
- «Что такое `BUS_POINT_ID` в DALI и чем он отличается от `CABLE_ID`?»
- «Вот снимок атрибутов блока — что не соответствует нашему reference?»

## Требования к ответу GPT

**Что сделать в AutoCAD → точные блоки/атрибуты → ссылка на документ → что не определено и требует согласования.**

Если файл не открылся или первоисточник недоступен, помощник должен честно сказать об этом, а не имитировать проверку. Неизвестные ID, марки кабеля, высоты, мощности, номера шин, способы прокладки и назначения клавиш **нельзя придумывать**.
