# Как запустить своего ChatGPT-помощника по чертежам NEIROLINKS

Этот способ рассчитан на **личный ChatGPT проектировщика**. Не нужно давать ему ваш аккаунт ChatGPT, ваши переписки, доступ на контроллеры или права на редактирование репозитория.

## Основной вариант: проект ChatGPT + GitHub на чтение

1. Проектировщик создаёт **новый Project** в собственном ChatGPT: например, `NEIROLINKS · Чертежи AutoCAD`.
2. Открывает настройки проекта и вставляет в **Project instructions** содержимое [PROJECT_INSTRUCTIONS.txt](PROJECT_INSTRUCTIONS.txt).
3. В разделе **Plugins/Apps → GitHub** проверяет, доступно ли подключение GitHub для его плана/режима. Если доступно, авторизует свой GitHub и выбирает **`psv76/Neirolinks`** для чтения. GitHub-подключение в ChatGPT ориентировано на поиск и чтение допустимых ресурсов; не является механизмом правки исходного кода.
4. В проекте/чате задаёт конкретную область знаний:
   ```text
   Работаем только с руководством NEIROLINKS по AutoCAD для NL Project 3.0.
   Сначала открой Systems/NLP/docs/training/README.md,
   затем AUTOCAD_LIGHTING_GUIDE.md и FAQ.md.
   Для точного имени блока, набора атрибутов и физической topology
   сверяйся с каноническими документами Systems/NLP/docs/autocad/
   и Systems/NLP/docs/product/.
   ```
5. Спрашивает по ходу работы, прикладывает **снимок свойств блока** (имя definition и видимые атрибуты) и объясняет, что хочет получить. Вопросы о новом правиле передаёт ответственному проектировщику.
6. Для работ на реальном объекте использует его **согласованное задание и библиотеку блоков**; руководства общего назначения их не заменяют.

**Важно:** доступность GitHub в стандартном чате, исследованиях и других режимах отличается по планам/интерфейсам. Не называем GitHub «автоматической постоянно синхронизируемой базой знаний»: подключённый ChatGPT запрашивает допустимое содержимое по необходимости. Если доступа через приложение нет, используйте резервный способ.

## Резервный вариант: Project + файлы

1. Открыть ссылку на папку справочника: [training на GitHub](https://github.com/psv76/Neirolinks/tree/main/Systems/NLP/docs/training) — **после принятия PR**. До принятия использовать [черновую ветку](https://github.com/psv76/Neirolinks/tree/docs/232-nlp3-cad-designer-guide/Systems/NLP/docs/training).
2. Скачать/сохранить локально необходимые документы **как текстовые файлы (.txt)** или поддерживаемые документы, включая `README`, `AUTOCAD_LIGHTING_GUIDE`, `FAQ`, а при необходимости — соответствующие канонические ссылки/документы с GitHub.
3. Добавить тексты в источники своего ChatGPT Project и вставить инструкции [PROJECT_INSTRUCTIONS.txt](PROJECT_INSTRUCTIONS.txt).
4. Раз в некоторое время **обновлять загруженные файлы** из принятого `main`: это **снимок на момент загрузки**, он сам не обновляется.

Этот вариант проще, но при вопросе по блоку, не описанному в загруженных файлах, GPT должен честно сказать, что в доступных материалах ответа нет.

## Хорошие вопросы к помощнику

- «У меня встраиваемый светильник 230 В в гостиной: какой наш canonical block, какие атрибуты и почему? Дай ссылку на норму».
- «В одном кабеле три выключателя. Как записать `CABLE_ID` и чего не должно быть в ATTDEF?»
- «Что означает `CABLE_SOURCE=111.01`? Может ли он быть пустым?»
- «Вот скриншот свойств `LIGHT_IN_230V`. Что не соответствует нашему exact reference?»
- «У меня DALI-светильник. Чем `CABLE_ID` отличается от `BUS_POINT_ID`?»
- «Не знаю допустимое значение `LED_TYPE`. Что говорит документация?»
- «После изменения чертежа NLP требует внимания. Какие факты нужно проверить, прежде чем решать конфликт?»

## Как должен отвечать помощник

Ответ желательно строить в порядке:

1. **Что сделать в AutoCAD сейчас** — коротко и без внутренней архитектуры.
2. **Какие именно имена/значения применяются** — с точными написаниями.
3. **Почему** — конкретная ссылка на нормативный раздел.
4. **Что неизвестно** — отдельный вопрос руководителю, без подстановки выдуманного значения.

Если приложение GitHub не вернуло актуальный документ, GPT должен обозначить это явно, а не выдавать общие знания AutoCAD за фирменный стандарт NEIROLINKS.
