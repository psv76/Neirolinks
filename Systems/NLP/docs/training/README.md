# NEIROLINKS · AutoCAD для NL Project 3.0

**Руководство проектировщика, учебная редакция 0.1 · 21.10.2026 · на проверке (draft)**

Этот раздел — **для человека, который проектирует**, а не для разработчика NL Project. Первая специализация: **освещение, выключатели, светодиодные линии, начальная кабельная топология**.

> **Важное различие:** NL Project 3.0 — текущая линия продукта. Часть действующих нормативных документов исторически озаглавлена «NL Project 2.0», однако их актуализированные разделы описывают принятый AutoCAD Repair 08 contract **3.0.0**. Ориентируемся на статус контракта и текущую документацию, а не только на заголовок старого файла. Это **не** означает, что любое старое DWG автоматически совместимо.

## Что проектировщик делает сам

1. Получает архитектурную DWG-подоснову и согласованную структуру зданий/помещений.
2. Размещает **наши канонические блоки** светильников, выключателей, кнопок, LED и, при необходимости, DALI.
3. Заполняет предусмотренные **атрибуты именно этих блоков**, не добавляя собственные теги и не переименовывая определения.
4. Назначает кабельные линии, щит и непосредственные источники физических участков в соответствии с выданной схемой.
5. Проверяет DWG по чек-листу, сохраняет его самостоятельно и передаёт на проверку/синхронизацию.
6. Исправляет замечания после обратной связи руководителя.

**Не входит в стартовую задачу:** правка исходников NLP, migrations, SQLite, настройка оборудования Wiren Board, самостоятельное изменение принятых стандартов или назначение наугад аппаратных портов.

## Маршрут обучения

| Этап | Что изучить | Контроль |
|---|---|---|
| 1 | Блок, вставка, атрибуты AutoCAD, единицы DWG | Найти имя блока и увидеть свойства вставки |
| 2 | Светильники 230 В, помещение, высота, нагрузка | Заполнить 2–3 светильника корректного типа |
| 3 | `CABLE_ID`, `BOARD`, `CABLE_SOURCE` | Нарисовать линию из двух светильников без обрыва связи |
| 4 | Выключатели и `KEY_n` | Показать общую линию выключателей с последовательностью `.ZZ` |
| 5 | LED, DALI и треки (второй уровень) | Отличать кабельную и шинную топологию |
| 6 | Проверка и передача DWG | Передать файл и список вопросов без угадывания значений |

## Как пользоваться источниками

**Учебный справочник не заменяет технический первоисточник**. Если сомневаетесь в точном имени блока или атрибута, проверяйте:

1. [Точный справочник 71 canonical blocks и ATTDEF](../autocad/AUTOCAD_BLOCK_ATTRIBUTE_REFERENCE.md) — первоисточник по именам и полям.
2. [Топология кабелей и шин](../autocad/CURRENT_TOPOLOGY_ARCHITECTURE.md) — первоисточник по физическим связям.
3. [Масштаб и геометрия AutoCAD](../product/20_AUTOCAD_BLOCK_CONTRACT.md).
4. [Кабельные сегменты, способ прокладки, трубы](../product/22_CABLE_LENGTHS_AND_CONDUITS.md).
5. [RS-485 / DALI](../product/23_DATA_BUS_TOPOLOGY.md).
6. [Правила обновления DWG ↔ NL Project 3.0](../product/25_DWG_SYNCHRONIZATION.md).
7. [Статус реализации](../STATUS.md) — не путать принятое правило с завершённой пользовательской приёмкой.

**Рабочая проблема → вопрос своему ChatGPT → ссылка на точное правило → проверка в DWG → если правило не определено, вопрос ответственному проектировщику.** Чат не должен изобретать стандарты.

## Важная оговорка о рабочем процессе

Команда **«Обновить»** в NL Project 3.0 предусмотрена как основной пользовательский сценарий синхронизации с подтверждённым DWG. Но **NL Project не сохраняет DWG автоматически**. Сохранять чертёж должен пользователь AutoCAD. Реальную готовность/версию интерфейса проверяйте на установленной сборке; этот учебник не является актом приёмки программы.
