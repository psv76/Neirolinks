# Защита от протечек NL Project 2.0

## 1. Neptun SW007

`Neptun SW007` учитывается как активный датчик протечки с питанием `24 В DC`, дискретным выходом и одним назначенным входом.

Питание допускается от общей шины `24 В DC`, питающей модуль ввода.

## 2. Локальное подключение к WB-MWAC

Датчик допускается подключать к одному входу `F1–F6`.

Для каждого входа задаётся действие: закрыть `K1`, закрыть `K2` или закрыть оба крана.

Локальный вход может воздействовать только на краны того же экземпляра `WB-MWAC`.

Связь локального входа одного `WB-MWAC` с краном другого `WB-MWAC` не допускается.

## 3. Удалённое подключение через WB-M1W2

Удалённый датчик занимает один вход `W1` или `W2` одного `WB-M1W2`.

Один удалённый датчик назначается ровно одному `WB-MWAC`.

Для него задаётся авария по `K1`, по `K2` или по обоим каналам.

Несколько удалённых датчиков допускается назначать одному `WB-MWAC`. Один удалённый датчик не должен быть назначен нескольким `WB-MWAC`.

## 4. Действие удалённого датчика

Сценарий должен переводить выбранный `WB-MWAC` в штатный режим протечки и передавать выбранный канал или оба канала.

Сценарий не должен управлять выходами кранов прямой записью состояния реле.

Если авария назначена только на `K1`, состояние `K2` не должно изменяться из-за этой аварии.

## 5. Ручной выход из аварии

Автоматическое повторное открытие кранов после исчезновения сигнала протечки не допускается.

Выход выполняется вручную командой интерфейса, кнопкой модуля или внешним выключателем на входе `S6`.

Вход `S6` использует штатную логику `WB-MWAC`. NL Project не должен представлять `S6` как произвольно назначаемую прямую команду отдельному крану.

## 6. Несколько модулей

На одной шине `RS-485` контроллера допускается несколько `WB-MWAC` и несколько модулей с удалёнными датчиками.

При этом локальный вход действует только внутри своего модуля, удалённый датчик имеет один целевой модуль, а целевые каналы задаются внутри выбранного модуля.

## 7. Проверки

Система должна выявлять датчик без питания, датчик без входа, повторное занятие входа, локальную связь с чужим модулем, удалённый датчик без цели или с несколькими целями, отсутствие выбранных каналов и автоматическое открытие после аварии.
