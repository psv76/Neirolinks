# Интерфейс объекта и учёт времени NL Project 2.0

## 1. Назначение

Документ определяет отображение текущего объекта, автоматический учёт времени работы с объектами, состав вкладки `Время работы` и структуру верхнего уровня дерева объектов.

Документ не определяет структуру базы данных, способ программной реализации, восстановление незавершённого периода после аварийного завершения приложения и ручное изменение учтённого времени.

## 2. Верхняя панель текущего объекта

Верхняя панель должна всегда отображать данные текущего открытого объекта.

Время работы должно отображаться в две строки:

1. первая строка — надпись `Сегодня`, количество часов и минут, учтённых для текущего объекта за текущий день;
2. вторая строка — надпись `Всего`, количество часов и минут, учтённых для текущего объекта за всё время, одна кнопка управления учётом времени и кнопка `Синхронизация с DWG`.

Количество времени должно отображаться в формате `<количество часов> ч <количество минут> мин`.

На второй строке элементы должны располагаться в следующем порядке:

1. общее время;
2. кнопка `Пауза` или `Play`;
3. кнопка `Синхронизация с DWG`.

## 3. Управление учётом времени

Для управления учётом времени должна использоваться одна кнопка с двумя взаимоисключающими состояниями.

Во время учёта кнопка должна иметь название `Пауза`. Нажатие кнопки должно остановить учёт времени текущего объекта и завершить текущий период работы.

После остановки кнопка должна иметь название `Play`. Нажатие кнопки должно возобновить учёт времени текущего объекта и начать новый период работы.

Кнопки `Пауза` и `Play` не должны отображаться одновременно.

## 4. Правила учёта времени

Время каждого объекта должно учитываться независимо от других объектов.

При открытии объекта учёт его времени должен начинаться автоматически.

При переключении на другой объект система должна завершить текущий период работы предыдущего объекта и автоматически начать учёт времени выбранного объекта.

Одновременно допускается не более одного активного периода работы.

При закрытии приложения активный период работы должен завершаться.

Период работы, пересекающий границу календарных суток, должен разделяться по этой границе. Время до границы суток относится к предыдущему дню, время после границы — к следующему дню.

Переключение вкладок и разделов внутри текущего объекта не должно завершать или заново начинать период работы.

Если пользователь остановил учёт времени кнопкой `Пауза`, переключение вкладок и разделов внутри того же объекта не должно возобновлять учёт.

При возврате к ранее открытому объекту учёт его времени должен начинаться автоматически независимо от состояния учёта перед переключением на другой объект.

## 5. Вкладка `Время работы`

Вкладка `Время работы`, предусмотренная документом `11_OBJECT_AND_ROOM_MODEL.md`, должна содержать только:

- время текущего объекта за текущий день;
- общее время текущего объекта;
- текущее состояние учёта: выполняется или остановлен;
- одну кнопку `Пауза` или `Play` по правилам раздела 3.

Вкладка не должна содержать отчёты, аналитику, ставки, сведения об исполнителях, экспорт и средства ручного изменения учтённого времени.

## 6. Дерево объектов

Надпись `ОБЪЕКТЫ`, отдельная строка или контейнер этой надписи и связанный с ними вертикальный промежуток не должны отображаться над деревом объектов.

Первым элементом дерева должен быть корневой элемент `Реестр объектов`, после которого должны отображаться корневые элементы проектов.

Корневые элементы дерева должны располагаться без дополнительного горизонтального отступа от левого края области дерева.

Вложенные элементы должны сохранять отступ, обозначающий их уровень вложенности.
