# Issue #216 / Q08 — подтверждение итоговой длины общей трубы

**Статус:** реализация в отдельной проверочной ветке поверх рабочей интеграции «Трасс» B (#301). Никакого изменения рабочих DWG/SQLite или публикации непроверенных 80 BUS-труб.

## Назначение

Реальное объединение 146.PP20 + 147.PP20 уже выполнено пользователем в NLP 3.2: 146.PP20 содержит отдельные CableSegment 204/205. Объединение не повторять. Утверждённый операторский допуск XY ≤ 1 м / ΔZ ≤ 2 м реализован PR #304 и остаётся неизменным. Обязательная привязка к FRAME_* **не вводится** (ошибочный PR #316 закрыт без merge).

Известная проблема: Q08 физическая `Conduit.length_m_decimal` после Merge нескольких cable segments имеет `NULL/INCOMPLETE_SHARED`. Старые 16 м двух отдельных труб нельзя автоматически принимать за итоговую длину одной трубы. Это не даёт права выбирать минимум/максимум или складывать длины кабелей.

## Реализованная узкая команда

В разделе «Трассы» B выберите **одну** трубу → «Подтвердить длину трубы». Предварительная проверка читает все CABLE/BUS members и версии, project revision и состояние Conduit. Оператор явно вводит **итоговую физическую длину трубы (м)**, указывает текстовое основание и ставит отдельную отметку подтверждения. Ввод не является ни суммой кабельных длин, ни длиной любого одного электрического окончания. При отмене — ноль записей.

Запись в одной транзакции под CAS project revision + Conduit row_version и повторным построением member snapshot:
- `Conduit.length_m_decimal = confirmed final m`
- `Conduit.path_json.length_source=USER_CONFIRMED`
- основание `manual_length_note`, `manual_length_basis`, точные CABLE/BUS segment IDs;
- инкремент `project_revision`, `Conduit.row_version`.

Запрещены неконечные/неположительные числа, отсутствие основания, пустая/RETIRED труба, неподтверждённые physical segments, устаревшая ревизия или изменившиеся назначения. Ни один electrical CableSegment, BusSegment, соединение, GOFRA_ID или DWG не меняется. Существующий `_refresh_conduit_length` уже защищает `length_source=USER_CONFIRMED` от автоматического пересчёта.

**Это ручное подтверждение достоверной итоговой длины, НЕ доказательство геометрии и не исправление 80 BUS Conduit по умолчанию.** Пока точная длина 146.PP20 проектировщиком не подтверждена, её live value остаётся `NULL`. В модель не добавляется обязательный FRAME_*.
