### DALI — редактирование и удаление

В **«Шины данных»** появились:
- кнопка **«Редактировать DALI»** — номер 9YY и назначение свободного физического DA1/DA2/DA3;
- **«Удалить шину»** теперь работает и для DALI, с обязательным подтверждением;
- запрещено перенумеровывать или менять DA-источник шины, у которой уже есть точки/трассы/ветви/группы; автоматическое изменение CABLE_ID по таким операциям запрещено;
- при подтверждённом удалении выбранной шины удаляются **только** её собственные точки, ветви, физические узлы/связи, группы, сегменты и привязки гофры; устройства, кондуиты, кабельный журнал и соседние шины сохраняются;
- RS485 и KNX остаются независимыми: новый редактор только для DALI, KNX не получает ложную возможность удаления.

### Совместимость и ограничения

- Без схемных миграций: каноническая схема `000000000017`, SQLite-файл продолжает называться `nl_project_3.sqlite`.
- Изменение заголовка GUI и `--version` на **NL Project 3.2 (release)**, штатный скрипт `START_NL_PROJECT_3.vbs` сохраняется без переименования.

- Предыдущая постановка `WB-23/MOD3` была *гипотетическим примером*. Никаких проверок или исправлений реальных экземпляров WB-23 не требуется и не запланировано.

## Release gate

Установка на рабочую SQLite разрешена только при **закрытых экземплярах NLP**:
1. Зафиксировать SHA-256 базы до операции; прочитать фактический schema head и активный release.
2. `verified backup` → штатный `apply_additive_catalog_successor.py` от текущего выпущенного predecessor `nlp3.equipment.2026-10-27.wbe2-rs485-iso` к 51/67.
3. Проверить не только PASS receipt, но также неизменность ID `project`, `project_instance`, `instance_resource`, `functional_relation`, `bus`, `PRAGMA integrity_check`, `foreign_key_check`, idempotence.
4. Startup smoke приложения NLP 3.2 с актуальным каталогом, подтверждение, что оно действительно открывает 3.2, а не старую копию `D:\NLP 3.1`.
5. Для полного закрытия Issue #293 остаются три неподтверждённые аппаратные ревизии и финальная операторская приёмка шина/кабель на отдельном объекте; этот релиз не объявляет их готовыми.
