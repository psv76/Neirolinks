# Issue #293 — операторская установка модулей в NL Project 3.1

**Источник истины:** `psv76/Neirolinks/main/Systems/NLP`.
**Состояние:** реализовано в исходниках и проверено на изолированной тестовой SQLite; на рабочем объекте GUI/последний каталожный successor ещё не принят.

## Задача пользователя

При трёх контроллерах `WB-20`, `WB-23`, `WB-26` по 4 MOD-слота инженер должен выбрать **именно WB-23 / MOD3** и нужный экземпляр WBE2-I-RS485-ISO, не выбирая служебные технические ресурсы `HOST_SLOT_ATTACHMENT` и не просматривая сотни ненужных строк.

## Реализованный пользовательский путь

В **«Инженерные подробности → Проектный конструктор → Установка модулей»**:

1. В поле **«Контроллер»** выбрать `WB-23`. В список попадают только существующие экземпляры со слотами физического расширения.
2. В поле **«Физический слот»** выбрать `MOD3 — свободен`; все MOD-слоты контроллера и их занятость одновременно видны в таблице ниже.
3. В поле **«Модуль»** выбрать `M01 — WBE2-I-RS485-ISO` из **уже созданных** экземпляров проекта. Если его ещё нет, создать на первой вкладке «Экземпляры и ресурсы». В выпадающем списке отображаются только совместимые и неустановленные модули; проверка выполнена штатным `preview_relation` Constructor.
4. Нажать **«Установить модуль»**. Это сохраняет типизированную `MODULE_INSTALLATION` и обновляет занятость.
5. Для извлечения выбрать занятый слот и **«Снять модуль»**; требуется подтверждение. Модуль, чей интерфейс корень активной шины, не извлекается.
6. Отдельный **MODEM** показывается только у контроллеров, которые действительно имеют соответствующий ресурс; `WBC2-4G` устанавливается через `MODEM_INSTALLATION`, не в `MOD3`.

**Важный предел функциональности:** эта форма устанавливает *уже созданный* модуль. Добавление самого экземпляра пока остаётся на первой вкладке; это не автоматическое создание торговой позиции из каталога.
