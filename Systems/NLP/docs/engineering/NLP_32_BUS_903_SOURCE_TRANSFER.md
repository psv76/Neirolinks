# NLP 3.2 — перевод существующей шины 903 на M01 / RS485

Статус: исправление подготовлено в исходниках; тестовая копия SQLite — PASS; рабочая SQLite пока не изменена, поскольку открыты процессы NLP.

## Действительный объект

- Шина 903, ID 2ebc5078-fe7b-4e50-906b-021c88684c36.
- Прежний источник: WB-21 / RS485.
- Новый источник: M01 / RS485, ID d8716e02-9f97-4c6e-8dc8-a3959350cf6e.
- M01 — WBE2-I-RS485-ISO, установлен в WB-20 / MOD1 (persisted MODULE_INSTALLATION).
- WB-21 и WB-20 располагаются в одном щите, board ID 30d26bf9-37fa-4baa-8673-7636c112184e.
- У шины пять точек 903.001–903.005 и пять сегментов; номера и длины менять нельзя.
- Обсуждение WB-23/MOD3 являлось гипотетическим примером; с текущим изменением не связано.

## Реализация

BusService.transfer_rs485_source проверяет RS485-тип, физическую установку WBE2 в MOD-слот, свободный корень и отсутствие конфликта с точками. Заполненную шину разрешено переводить только на порт в том же щите. Обновляется только bus.root_resource_id, ID 903, адреса, сегменты, монтажные поля, длины, устройства и остальные шины не меняются.

В интерфейсе «Шины данных» добавлена команда «Изменить источник RS-485»: выбрать 903, затем M01 / RS485 и подтвердить. Номер шины в диалоге недоступен для изменения.

Подготовлен защищённый инструмент tools/transfer_rs485_bus_source.py. Он требует закрытия всех процессов NLP, проверяет SHA-256 рабочей базы, schema head, ожидаемый old-root, новый M01 и 5/5 элементов шины, выполняет verified backup, вызывает штатный BusService и сверяет неизменность всех связанных записей, после чего проверяет SQLite integrity и FK. Прямое редактирование SQLite запрещено.
