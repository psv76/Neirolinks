# Проверочные случаи нарезки LED-лент и закупочных катушек

## 1. Назначение

Таблица проверяет нормативный раздел «Нарезка лент и расчёт закупочного количества» документа `docs/product/21_LED_LINES_AND_PWM_EQUIPMENT.md`. Это критерии будущей реализации, а не исполняемый тест production-кода.

Все длины указаны в миллиметрах. Вычисления используют десятичные значения товара без скрытого допуска:

```text
CUT_LENGTH = ceil(DESIGN_LENGTH / CUT_INCREMENT) × CUT_INCREMENT
```

| ID | Действие | Ожидаемый результат |

## 6. Спецификация

| ID | Условие | Ожидаемый результат |
|---|---|---|
| `LED-SPEC-001` | результат `LED-REEL-001` | одна позиция `product.arlight.048822` в данной области поставки; единица `заводская катушка 15 м`; количество 2; пояснение: закуплено 30000 мм, остаток 4000 мм |
| `LED-SPEC-002` | одинаковый `PRODUCT_ID` в двух областях поставки | две независимые позиции или две строки разбиения одной спецификации с явной областью; количество не объединяется между областями |
| `LED-SPEC-003` | отсутствует `SALE_MODE`, `REEL_LENGTH` или `MIN_PURCHASE_INCREMENT` | ошибка неполных данных товара; закупочная позиция не формируется |
| `LED-SPEC-004` | товар подтверждён как `LENGTH_BASED` | количество в единицах длины округляется вверх до `MIN_PURCHASE_INCREMENT`; это правило не применяется ни к одной из шести канонических лент Arlight MVP |

## 7. Критерий прохождения

Будущая реализация проходит набор только при точном совпадении ошибок, `CUT_LENGTH`, состава групп, числа катушек, закупочной длины, остатка, мощности и результата спецификации. Изменение порядка исходных строк не должно менять итог, если стабильные идентификаторы участков не изменились.
