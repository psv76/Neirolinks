# 1. Правила обработкти

## 1.1. Входные данные парсера

DXF → BLOCK REFERENCES (INSERT)

Для каждого блока нас интересует:

1. Имя блока

2. Атрибуты блока

3. Координаты (потом пригодятся)

4. Layer (в будущем — контроль зон)

## 1.2. Валидационная модель

### 1.2.1 Имя блока

Формальная проверка:

```JSON
^[A-Z0-9]+(_[A-Z0-9]+)*(_IP[0-9]{2})?$
```

Ошибки:

- lowercase

- пробел

- неизвестный тип

- неизвестная модификация

---

# 2. Ошибки делим на 3 уровня

CRITICAL — блок не участвует в журнале
ERROR — блок участвует, но с пометкой
WARNING — информативно

Пример:

- нет DEVICE_TYPE → CRITICAL

- нет ID (если не FRAME) → ERROR

- неизвестный LOAD_TYPE → ERROR

- имя блока не по стандарту → WARNING

> Имя блока = визуальный тип
DEVICE_TYPE = логический тип
Они обязаны совпадать.

Несоответствие → **CRITICAL ошибка**.

CABLE_TYPE

COMMENT_1

COMMENT_2

CABLE_TYPE

COMMENT_1

COMMENT_2

CABLE_TYPE

COMMENT_1

COMMENT_2

# 3. Работа в AutoCAD

Все устройства, которые должны быть обработаны должны находиться в стандартных слоях:

|Слой AutoCAD|Распределение DEVICE_TYPE по слоям|
|-|-|
|100|SOCKET, CABLE_OUTLET, BOARD, FRAME|
|200|SWITCH, BUTTON, FRAME|
|300|LIGHT, LIGHT_LED, CABLE_OUTLET|
|400|SENSOR|
|500|MOTOR, CABLE_OUTLET|
|600|HEATING_DEVICE, CABLE_OUTLET|
|700|RELAY_DEVICE|
|800|NETWORK_DEVICE, CABLE_OUTLET, SOCKET_ETHERNET|
|900|BUS, CABLE_OUTLET, SENSOR|

Если ID одинаковый, значит должны быть одинаковые:

CONTACT

BOARD

ROOM

CABLE_TYPE

Если ID одинаковый, а LOAD_NAME разный, значит пишем в одну ячейку, через запятую.

# 4. Заполнение шаблона "Кабельный журнал"

"Откуда (щит)" - BOARD

"Куда (помещение)" - ROOM

"Маркер кабеля" - ID

"Название устройства" - LOAD_NAME

"Марка кабеля" - CABLE_TYPE (если указан)

"Длина линии, м" - не заполняем

"Питающий автомат" - заполняем CONTACT если в CONTACT первая буква "Q"

"Модуль управления" - если в поле CONTACT, CONTACT_1, CONTACT_2, CONTACT_2, CONTACT_4 первая буква "A", то берём значение до точки. Т.е если там будет "A03.in3", то пишем "A03". Это для сортировки надо

"Управляющий контакт" - заполняем CONTACT, CONTACT_1, CONTACT_2, CONTACT_2, CONTACT_4 (все в одну ячейку через запятую), если в CONTACT первая буква не "Q"

"Оборудование" - не заполняем

То есть: если в CONTACT первая буква "Q",

то значение пишем в "Питающий автомат",

иначе значение пишем в колонку "Управляющий контакт". Либо туда, либо туда.

И еще надо добавить замену:

если CABLE_TYPE="3х2,5" то в "Марка кабеля" пишем "ВВГнг(А)-LS 3х2,5"

если CABLE_TYPE="3х1,5" то в "Марка кабеля" пишем "ВВГнг(А)-LS 3х1,5"

если CABLE_TYPE="UTP" "UTP 5e" то в "Марка кабеля" пишем "UTP 5e 4х2х0,5"

добавить строгий контроль допустимых CABLE_TYPE по типу линии X.

## 4.1. Итоговая логика журнала

### ✔ Контакты:

- `Q*` → "Питающий автомат"

- остальные → "Управляющий контакт"

- `A03.in3` → модуль `A03`

### ✔ Кабель:

- нормализуется автоматически

- неизвестные типы не ломают код

### ✔ Контроль:

- проверяется конфликт board / room / cable_type

- LOAD_NAME агрегируются

- сортировка по числовому ID
