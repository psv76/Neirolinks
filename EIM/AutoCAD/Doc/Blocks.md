# 1. Имя блока

## 1.1 Общий принцип

<ТИП>_<МОДИФИКАЦИЯ>[_IPXX]

- только UPPERCASE

- только латиница

- разделитель — `_`

- без пробелов

- IP указывается только если ≠ IP20

# 2. Атрибуты блока

## ID

#### Назначение

идентификатор электрической линии / канала / шины

#### Формат

XYY.ZZ

X — тип линии

YY — порядковый номер линии (строго две цифры)

.ZZ — номер конкретного устройства внутри группы (опционально, но строго две цифры)

Формат XYY может иметь несколько дублей

Формат XYY.ZZ - уникальный

#### Ошибки:

- lowercase

- пробел

- неизвестный тип

- неизвестная модификация

## DEVICE_TYPE

#### Назначение

Физическая классификация устройства на плане. Он отвечает на вопрос: Что это за устройство?

DEVICE_TYPE не определяет группу и не определяет управление.

#### Допустимые значения

**SOCKET** - розетки

**LIGHT** - светильники 

**LIGHT_LED** - светодиодные ленты

**SWITCH** - выключатели с фиксацией, переключатели с фиксацией

**BUTTON** - кнопки (выключатель без фиксации)

**FRAME** - рамки

**CABLE_OUTLET** - Кабельные выводы (котлы, варочные поверхности, кондиционеры, бризеры, стационарные приборы, БП светодиодных лент). Это **физическая точка подключения без розетки**.

**SENSOR** - датчики

**MOTOR** - двигатели, приводы, насосы

**HEATING_DEVICE** - отопительное оборудование (котлы, обогреватели, конвекторы, тепловые насосы)

**RELAY_DEVICE** - реле

**NETWORK_DEVICE** - роутеры, коммутаторы, IP шлюзы

**BUS** - шины данных (RS-485, e-Bus, OpenTherm, Dali, knx)

**BOARD** - электрический щит

Примечание: для **DEVICE_TYPE** = FRAME ID не требуется и в кабельный журнал не попадает.

## LOAD_TYPE

### **SOCKET** Допустимые значения для розеток

**SOCKET_LIVING_LOW** - Бытовые розетки жилых комнат. Группируем не более 6 постов на группу, не более 3,5 кВт на группу. На каждую комнату свои группы (если более одной). 

**SOCKET_LIVING_MEDIUM** - Высоко нагруженные бытовые розетки (утюг, электрочайник в беседке, обогреватель). Не более трёх на группу, не более 3,5 кВт на группу. По мощности сопоставимо с двумя SOCKET_LIVING_LOW, соответственно можно на группу 2 шт SOCKET_LIVING_MEDIUM и 2шт SOCKET_LIVING_LOW 

**SOCKET_CONTROL_LOW** - Управляемая розетка до 8А. Гирлянды, ёлки, торшеры. Управляются напрямую модулями WB-MR6C 

**SOCKET_CONTROL_MEDIUM** - Управляемая розетка от 8А до 14А. Питание оборудования или обогревателей. Управляется модулями WB-MR6C, но через модульные контакторы. 

**SOCKET_KITCHEN_MEDIUM** - не управляемые розетки фартука. Отдельная линия на каждый розеточный блок. 

**SOCKET_KITCHEN_HIGH** - выделенная линия под мощное оборудование кухни (СВЧ, духовой шкаф, мощная кофемашина). 

**SOCKET_KITCHEN_3PH** - Трёхфазная розетка. Выделенная линия. Например, если варочная поверхность подключается через трёхфазную розетку.

**SOCKET_ETHERNET** - Интернет розетки.

### **LIGHT** Допустимые значения для освещения

**LIGHT_MAIN** - основной свет 

**LIGHT_DECOR** - декоративная подсветка 

**LIGHT_TECH** - Технический свет 

**LIGHT_NIGHT** - ночная подсветка. Работает по датчику движения в ночное время. 

**LIGHT_STREET** - уличное освещение. включается по закату, выключается в час ночи и до рассвета только по датчику движения.

### **CABLE_OUTLE** Допустимые значения для кабельных выводов

CABLE_BOILER

CABLE_HVAC - кондиционеры, вентиляционные установки, бризеры. Электроснабжение не контролируем. 

CABLE_HEAT - отопительные котлы, насосы, коллекторные шкафы. Контролируем подачу питания модулями WBIO-DI-HVD-8, а всё остальное делим на оборудование и освещение. 

CABLE_TECH - общая группа для какого-либо оборудования, типа полотенцесушитель, вытяжка если не в розетку, вентиляторы в санузлах, приводы штор, какие-нибудь насосы, например для полива. 

CABLE_LIGHT_DECOR 

CABLE_LIGHT_TECH 

CABLE_LIGHT_NIGHT 

CABLE_LIGHT_STREET

BOARD_METER - Щит учета

BOARD_IN - Вводно-распределительный
