# Онигири — SVG-панель

По сообщению пользователя SVG «Холодильная установка» уже загружена на контроллер. В экспортированном `wb-webui (1).conf` имеется SVG `Fridge/svg/current` (3 511 821 байт UTF-8) с SHA256 `04b0094cd8a98c1c10d9b837490bc44e5f3370dc047b88cb6f16853dbee5ac4c`. Это **точное совпадение** с v4.4, подготовленной в проектном чате «Онигири». Полный SVG пока в GitHub не выгружен, для следующих этапов нужен оригинальный файл. `svg.params=[]`: MQTT-привязки не подтверждены.

## Визуальные элементы (ID найдены в SVG; семантика на проверку)
- `evap_fan_1`, `evap_fan_2` — ВО, два вентилятора;
- `cond_fan_1`, `cond_fan_2` — КД, два вентилятора;
- `evap_coil` — теплообменник ВО;
- `heater_pan`, `heater_diffuser_1`, `heater_diffuser_2` — ТЭН поддона, ТЭНы диффузоров (не подтверждены отдельные физические сигналы).

## Технические требования
Только вращающиеся лопасти (не решётки), точно вокруг ступицы; без биения. Корпуса/тройники/трубы сохраняют геометрию. Реальная температура — из `wb-w1/28-0000109d9767` после проверки; давления только после подтверждения соответствия P₀/Pc двум аналоговым входам. Красно-оранжевый горячий газ, оранжевые активные ТЭНы, красные аварии. Оттайку и клапаны не анимировать как подтверждённые без отдельного факта. Два вентилятора ВО нельзя честно анимировать независимо на основании одного `EXT1_IN4` без определения смысла сигнала.

Вкладка «Демо SVG Dashboard» экспортирует потенциальные управляющие привязки, её **не использовать как объектный HMI**.
