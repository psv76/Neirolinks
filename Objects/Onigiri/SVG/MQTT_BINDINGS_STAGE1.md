# SVG / Oniгири — первый этап MQTT привязок (v4.5, подготовлено офлайн)

Головная задача [#305](https://github.com/psv76/Neirolinks/issues/305).

## Подтверждено пользователем
- `wb-gpio/EXT1_IN3` = 1 — компрессор КМ работает; 0 — не работает.
- `wb-gpio/EXT1_IN4` = 1 — вентиляторы ВО работают; 0 — не работают.
- `wb-w1/28-0000109d9767` — вход температуры по экспорту WebUI; значения и свежесть live не проверены.

## Подготовленные привязки HomeUI
[SVG_bindings_stage1.json](SVG_bindings_stage1.json) — массив `svg.params` из 9 привязок, все только чтение:
- `value_temperature`: read c 1-Wire;
- `km_status_led`: зелёный / серый по `EXT1_IN3`;
- `evap_fan_1_rotor`, `evap_fan_2_rotor`: вращение по `EXT1_IN4`;
- `evap_fan_1_active`, `evap_fan_2_active` и `evap_fan_1_idle`, `evap_fan_2_idle`: видимость активных/неподвижных лопастей;
- `airflow_on`: индикация движения воздуха по `EXT1_IN4`.

Эти ID есть в **локально подготовленной v4.5**, сделанной из принятой v4.4 с добавлением ID к существующим изображениям крыльчаток и индикатору КМ. Геометрия и вращательные центры не менялись. Полный файл SVG v4.5 ещё не включён в GitHub: он передан тестовым ZIP в проектном чате; перед дальнейшим внедрением необходимо сохранить артефакт с точным SHA256.

## Контроль безопасности
Не применять массив JSON к старой v4.4 без добавленных ID, не импортировать полный старый экспорт `wb-webui.conf` на live. Сначала backup конфигурации и текущего SVG, затем установка SVG v4.5 и импорта `svg.params` в *редакторе существующей* панели «Холодильная установка» (ID Fridge).

`EXT1_IN4` — один общий сигнал. Он допускает синхронное вращение обеих лопастей для мнемосхемы, **не доказывает** индивидуальную работоспособность двух моторов. Контроль потери связи, устаревших MQTT и серверной доступности нуждается в отдельном мониторинге: одних read/style-привязок недостаточно для индикации `unknown` после обрыва.

Потоки хладагента, клапаны, оттайку, ТЭНы, аварии и давления по неподтверждённым каналам не привязывать.

Тест офлайн: Chromium вручную применил те же inline-стили к четырём состояниям графических элементов; проверены `animationName`, `opacity`, `fill` и центры `transform-origin`. HomeUI на контроллере пока не проверен, deployment отсутствует.
