# Онигири — мониторинг холодильной установки

**Объект:** «Онигири» (номер объекта **не указан**; каталог `Objects/Onigiri` создан без выдуманного кода).

## Назначение и границы
Заказчик — профессиональный поставщик промышленного холодильного оборудования, обеспечивающий штатное управление холодильной автоматикой. NEIROLINKS обеспечивает **только мониторинг, обнаружение неисправностей, уведомления и SVG-мнемосхему** на Wiren Board. Не вмешиваться в технологические команды компрессора, клапанов и оттайки.

## Основания и фактическое состояние
- [Проверено] Пользователем 2026-10-30 передан экспорт `wb-webui (1).conf`, в котором есть панель «Холодильная установка» и виджеты сигналов. Источник хранится в чате/передан пользователем, его хеш и выжимка интерфейсных привязок — в `Sources/`; **полный файл экспорта в репозиторий пока не загружен**.
- [Проверено] По сообщению пользователя SVG-панель уже загружена на контроллер. В экспорте присутствует полностью совпадающая по SHA256 графика версии v4.4, но `svg.params=[]`. Это не подтверждение готовой MQTT-анимации.
- [Не могу проверить] Live-контроллер, схема монтажа, физический тип входов, полярности, температура/давления в работе, наличие и состояние JS-скриптов, установленная версия ОС/WB и способ доставки уведомлений.

## Разработка
Следовать [EIM Development lifecycle](../../EIM/Standards/Development_lifecycle_standard.md): Issue → ветка от `main` → проверки → PR → merge → отдельно согласованная установка и live acceptance. `main/Objects/Onigiri` означает документацию **известного состояния**, а не то, что мониторинговые правила уже внедрены.

При дальнейшей работе **не использовать этот экспорт для перезаписи live WebUI**: он содержит demo-панели с управляющими привязками, не относящимися к холодильной автоматике.
