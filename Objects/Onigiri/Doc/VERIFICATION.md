# Онигири — проверки и неизвестные

## Проверено офлайн (только экспорт)
- Формат JSON `wb-webui (1).conf`, четыре панели, 13 виджетов; четыре объектовых виджета содержат 16 реальных WB-ID в поле `id`. Разделители не считаются каналами.
- Панели: Demo Dashboard, Demo SVG Dashboard, «Холодильная установка», «Сигналы».
- `Fridge/svg/current` совпадает побайтно по SHA256 с представленной в проектном чате SVG v4.4: `04b0094cd8a98c1c10d9b837490bc44e5f3370dc047b88cb6f16853dbee5ac4c`; `svg.params=[]`. Это факт экспорта, не live анимации.
- `Sources/webui_object_channels.json` представляет только объектовую выборку; полный файл не опубликован на GitHub. Сверка при новом экспорте обязательна.

## До включения аварий, по убыванию приоритета

| Проверить | Почему | Сейчас |
|---|---|---|
| Дата/актуальность экспорта, serial/hostname, firmware, installed `/etc/wb-rules` | Не заменить существующий live-функционал | Не проверено |
| `wb-gpio/EXT1_IN1,IN3–IN13`, схема электрического подключения | Где стоят сухие контакты, NO/NC, инверсия, какая «1» аварийная | Не проверено |
| `MODULE.CHANNEL` и аппаратная маркировка | Каноническая идентификация EIM | Не проверено |
| `wb-mai2-mini_197/input_1_value`, `input_2_value` | P₀/Pc, диапазон, bar, пересчёт, обрыв/устаревание | Не проверено |
| `wb-w1/28-0000109d9767` | Тип/место датчика, зависание и точность | Не проверено |
| `wb_ups_v3_92/battery_status`, `EXT1_IN1` | Состояние питания, качество, критерии аварии | Не проверено |
| RKS/HP/LP и сигнал «Авария ТЭН ВО» | Точные смыслы от холодильщиков и классификация | Не проверено |
| КМ/ВО/КД, два вентилятора, оттайка | Одного бита ВО недостаточно для раздельного контроля двух вентиляторов | Не проверено |
| Политика событий | Таймеры, антидребезг, краткие аварии, восстановление и приоритет | Не утверждено |
| Telegram или другой механизм доставки | Канал, доставка, восстановление, offline watchdog | Не проверено |
| Реальное поведение SVG | Вращение/цвета по подтверждённым топикам | Нужна проверка на WB |

## Условия допуска
До подтверждения активных уровней и реальных сигналов допускаются только разработка, офлайн-тесты, анализ. **Никаких управляющих записей в холодильную установку и искусственного воздействия на её контакты без отдельного согласования.** Установка скриптов на live — отдельный этап с backup, проверками и откатом.

Стандарты: [WB coding](../../../EIM/Standards/WB_coding_standard.md), [WB logging](../../../EIM/Standards/WB_logging_standard.md), [Issue #305](https://github.com/psv76/Neirolinks/issues/305).
