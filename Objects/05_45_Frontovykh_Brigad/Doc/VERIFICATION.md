# Проверки и неизвестные данные

## Выполненные офлайн-проверки

- JSON исходного файла разобран, все widget ID уникальны, ссылки dashboards на widgets разрешаются.
- Независимый рекурсивный обход всех полей `id`/`channel` с WB-ссылками сопоставлен с реестром вхождений. Учтены отключённые SVG-привязки; разделители исключены явно.
- 98 дискретных объектовых привязок + температура и влажность; demo/service хранятся отдельно.
- Извлечение воспроизводимо: `python Tools/extract_channel_map.py --check` сравнивает байты карты, паспорта источника, SVG и JSON панели с исходником.
- XML «Плана» разобран; `svg.params` пуст, `svg.original` — пустой объект. `Plan.svg` сохраняет строку `svg.current` в UTF-8 без переразметки. SVG не дорабатывался; браузерная анимация и отображение на WB не испытывались.
- Исходный экспорт сохраняется побайтно, SHA256 указан в `Sources/manifest.json`. Git-атрибуты исключают преобразование переводов строк исходного `.conf` и извлечённого SVG.

## Условия дальнейшей работы

Только после сверки каналов разрабатывать обработку аварий и сообщения. Затем проверять восстановление через WB widgets/SVG. Grafana подключать для последующего анализа. Проверка на действующем объекте должна быть согласована с ответственным за холодильную автоматику; искусственное воздействие на оборудование в рамках этой задачи не выполнялось.

Наличие карты в main означает принятую документацию предоставленного снимка. Оно не означает внедрение, доставку уведомлений, завершённую ПНР или соответствие live.
