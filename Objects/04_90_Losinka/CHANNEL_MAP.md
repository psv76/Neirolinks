## Следующий снимок для окончательной карты

В WB Cloud открыть **NEIROLINKS Service Tools → Сервис → «Собрать карту»**. Это `nst onboarding channels`; нужен **второй** архив, включающий:

- `config/etc/wb-webui.conf` — виджеты и подписи;
- `widget-channels.csv` — таблицу MQTT привязок к виджетам;
- `channel-map.json` — сопоставление с перечнем модулей и MQTT metadata;
- данные о недостающих подписях и `meta.warnings`.

После получения второго архива составить поканальную карту: `device_id/control_id`, дословная подпись, панель, модуль, предполагаемая зона, статус проверки, несоответствия. Особое внимание — устройству адреса **164 без MQTT ID**.

**Эксплуатационная безопасность:** данные собраны read-only. Объектный controller profile имеет `state=planned`; `nst sync`, изменение конфигурации Modbus, правил WB и исполнительных выходов не выполнялись.
