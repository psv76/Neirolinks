# 04 42 Ласточка — карта каналов и оборудования

Статус: **первичная карта из конфигураций, 17.10.2026; физическая приёмка не проводилась**.

## Источники и границы достоверности

- **[SERIAL]** — пользовательский снимок `wb-mqtt-serial (8).conf` (список RTU устройств/адресов/портов/настроек). Названия комнат и назначение выходов из этого файла не следуют.
- **[WEBUI]** — пользовательский снимок `wb-webui (6).conf`: имена и MQTT-идентификаторы виджетов «Отопление» и «Электроэнергия». Это *назначения, указанные в интерфейсе*, а не независимая проверка подключения.
- **[ОПЕРАТОР]** — описание объекта и согласованные решения по автоподпитке от 17.10.2026.
- Данных живого MQTT, исходников правил `wb-rules`, Sprut DISCOVER, фактической распиновки щита и актуального списка виртуальных термостатов **нет**. Нельзя считать перечисленные ниже каналы проверенными в действии.
- В [SERIAL] поле `channels[].enabled=false` отключает перечисленные дополнительные/служебные каналы драйвера; оно **не доказывает**, что всё устройство, его базовая температура или внешний датчик выключены.

## 4. Котельное оборудование и автоподпитка №414 [WEBUI, ОПЕРАТОР]

| Функция | MQTT `device/control` | Примечание |
|---|---|---|
| Газовый котёл, управление по сухому контакту | `wb-mr6cu_35/K5` | назначение из виджета |
| Электрический котёл | `wb-mr6cu_35/K4` | назначение из виджета; сценарий использования не подтверждён |
| Насос циркуляции ГВС | `wb-mr6cu_217/K5` | назначение из виджетов |
| Клапан подпитки отопления | `wb-mr6cu_196/K5` | физический writer должен оставаться на WB |
| Датчик давления подпитки, №414 | `wb-mai2-mini_46/input_1_value` | [SERIAL]: вход 1 настроен 0…6000; единицы/масштаб MQTT проверять |
| Подача | `wb-m1w2_75/External Sensor 1` | |
| Обратка | `wb-m1w2_75/External Sensor 2` | |

**Согласованный алгоритм №414 (требует сверки с действующим скриптом, не является подтверждением live-кода):**
- операторская поправка: показание для сопоставления с котлом = значение датчика 414 − **0,2 бар** (параметр изменяется из виртуального устройства);
- старт при давлении котла ≤ **1,0 бар** (датчик без поправки ≤1,2 бар), подтверждение **15 с**;
- целевое завершение ≥ **1,2 бар** по котлу (датчик ≥1,4 бар);
- один импульс клапана не более **3 с**, пауза **20 с**, повторная проверка давления; после успешного цикла пауза **120 с**;
- блокировки/защиты, причины, доступные таймеры, сообщения и полный программный сброс — согласно фактическому скрипту. Сброс **не должен** обходить физически опасное давление, неисправность датчика и аппаратные защиты.

`lastochka_pressure_makeup` — согласованное виртуальное устройство WB; **его точный набор controls необходимо прочитать из live `wb-rules`**, данного экспорта недостаточно.

## 6. Защита от протечек и освещение

- [ОПЕРАТОР] В Sprut настроен сценарий защиты от протечек воды.
- [SERIAL] На RS485-2 обнаружен WB-MWAC v.2 с Modbus ID **101**. Из приложенных файлов не следует, какие его входы/выходы подключены и участвует ли он в сценарии Sprut. Источник датчиков и физическая схема запорных кранов не представлены.
- [ОПЕРАТОР] Автоматизированного управления освещением **нет**. Наличие нерасписанных выходов MR6CU не означает, что ими управляется свет.
