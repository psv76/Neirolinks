# Карта физических каналов объекта 05 31 Иволга 13

Каноническое название объекта: **05 31 Иволга 13**. Допустимые краткие названия: **Иволга**, **Иволга 13**, **05 31 Иволга**.

## Статус и правило актуальности

Карта собрана по состоянию на **2026-09-07**.

Основной источник для текущих назначений каналов — актуальный `wb-webui.conf`, присланный с объекта 2026-09-07. Старые таблицы в `README.md` и `Doc/05 31 Ivolga info.md` использованы только для сверки и выявления расхождений.

Карта описывает **физические каналы, датчики и исполнительные механизмы**. Виртуальные устройства, controls скриптов, диагностические параметры и программные состояния здесь не перечисляются.

> **Временно / требует полевой проверки:** назначение помещений **«Гостевая спальня»** и **«Кабинет»** несколько раз менялось заказчиком. До физической проверки датчиков и прогрева пола текущий `wb-webui.conf` считается рабочей версией истины:
>
> - Гостевая спальня: `902.10`, `902.11`, `A08/K4`, `A09/K2`;
> - Кабинет: `902.08`, `902.09`, `A08/K5`;
> - радиаторный канал кабинета в текущем виджете не показан и требует отдельной проверки.
>
> После проверки отклика датчик → сервопривод и фактического прогрева пола эти строки должны быть подтверждены или исправлены.

## 10. Зафиксированные расхождения со старой документацией

1. **Датчики 413–420 котельной.** Старые таблицы README содержали неверные адреса M1W2. Актуальные привязки по текущему WebUI:
   - `413/414` → `wb-m1w2_141`;
   - `417` → `wb-m1w2_121`;
   - `418/419` → `wb-m1w2_173`;
   - `420` → `wb-m1w2_166`.

2. **KM3 Подсветка дорожек.** Актуальный контроль состояния — `wb-gpio/EXT1_IN7`. В одной из старых таблиц README был ошибочно указан `EXT1_IN6`.

3. **Гостевая спальня / кабинет.** Старые таблицы и текущий WebUI расходятся по `A08/K4`, `A08/K5` и радиаторным каналам. На 2026-09-07 временно приняты назначения текущего WebUI. Требуется полевой тест.

4. **MQTT-имена климатических датчиков дома.** Старые записи вида `902.14/Temperature`, `902.13/input_1_value` заменены фактическими устойчивыми именами новых MQTT-алиасов, например:
   - `902.14_MSW_TH/Temperature`;
   - `902.13_M1W2_LEAK_TEMP/External Sensor 2`;
   - `902.05_MSW_THM/Current Motion`.

5. **Протечки дома.** Старый раздел документации был незаполнен. В текущей карте зафиксированы фактические датчики из актуального WebUI.

## 11. План проверки на объекте

Для помещений «Гостевая спальня» и «Кабинет»:

1. Поочерёдно включить `A08/K4` и `A08/K5`.
2. Проверить, какой физический сервопривод открывается.
3. Нагреть контуры и определить фактический пол по росту температуры соответствующего датчика.
4. Проверить `A09/K2` и найти фактический канал радиатора кабинета, если он существует.
5. После натурной проверки обновить эту карту и пользовательские названия в WebUI / Sprut.
