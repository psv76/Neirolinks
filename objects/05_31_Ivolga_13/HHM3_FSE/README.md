# HHM3 FSE — 05 31 Иволга 13

## Текущая программная ревизия

Исправление PR #63 поверх установленного в объекте комплекта PR #60. Три изменяемых файла котельной:

- `modules/HHM3Outputs.js` — принятие команды без ложного ожидания публикации MQTT и без заявления о физической работе насоса/клапана; прямой Switch ON не отправляется, закрытие — только Switch OFF, Level сохраняется. Ошибка записи Level/насоса/OFF не выдаёт готовность и запускает попытку OFF.
- `modules/HHM3Circuit.js` — убрана искусственная минутная стадия насоса с закрытым горячим входом. Температурные защиты и предусмотренная отдельно защитная рециркуляция остаются.
- `boiler/wb-rules/500_HHM3_FSE.js` — операторские статусы вместо сырого JSON в WebUI; JSON остаётся доступен по MQTT как скрытые каналы; нулевой известный спрос не ошибочно маркируется как отсутствие данных. Вычисленная команда никогда не называется доказательством механического движения.

Остальные исходники и конфигурация объекта сохраняются: 620, беседка 624, 507 подпитка, Sprut, MQTT, OT, ГВС и другие контроллеры. Исходный рабочий комплект находится в PR #60. Issue #61 описывает историческую несовместимость wb-rules 2.40.0; котельная впоследствии обновлена до 2.46.5. Версия беседки в этом выпуске не меняется и не подтверждена заново.

## Контракт управления A05

Положительный целочисленный `A05/Channel N Dimming Level` вызывает AUTO-ON. Прямых команд `Switch ON` в скрипте нет. Закрытие горячего входа — `Switch OFF` без изменения последнего Level. Успешное присваивание в `dev` означает только принятие команды программой; MQTT readback диагностический, не доказательство положения клапана, циркуляции или наличия питания. При синхронной ошибке записи новая заявка контура запрещается, предпринимается Switch OFF, после восстановления повтор автоматический. Контроллер не должен останавливаться из-за отсутствующего повтора неизменного MQTT состояния за 10 секунд.

## Известные границы готовности

Программные модельные тесты **не являются физическими испытаниями**. На объекте ещё требуется отдельная приёмка фактического хода 560/561/562, температур, насоса и пути циркуляции, режима отключения только CH с сохранением ГВС (`source.noDemandMode='unconfirmed'`), 504 `FLOOR_SENSOR_INVALID` и интерфейса WB после применения. До завершения этих проверок статус — подготовленный выпуск для контролируемой установки и ПНР, не акт ввода отопления в эксплуатацию.
