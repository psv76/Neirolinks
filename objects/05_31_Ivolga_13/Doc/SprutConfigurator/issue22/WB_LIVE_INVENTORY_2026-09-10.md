## 3. Consequence for Project → YAML

The legacy Project extractor correctly provides functional/project identity, but legacy Modbus addresses cannot be trusted as current runtime addresses.

The useful boundary is therefore:

```text
Project identity + function
          +
current WB identity evidence
          ↓
normalized Sprut source model
          ↓
Sprut YAML v2
```

Configurator YAML must continue to use stable Project/WB aliases, never raw Modbus slave addresses as long-term identity.
