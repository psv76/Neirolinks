# Sprut Templates — 05 31 Иволга 13

Объектовый набор кастомных шаблонов, необходимых для восстановления Sprut.hub Иволги.

## Сохранено в репозитории

```text
05_31_Ivolga_Relay_Lightbulb.json
NL_simple_thermostat.json
```

`NL_simple_thermostat.json` также является общим reusable-template и хранится в общей библиотеке `Templates/Sprut/Heating/`; здесь лежит объектовая копия deploy-набора.

## Используемые на объекте профильные templates, исходники которых пока не найдены в репозитории

По ранее проверенной архитектуре на объекте используются кастомные профили WB-MSW4:

```text
WB-MSW4_TH
WB-MSW4_THM
WB-MSW4_M
WB-MSW4_CO
WB-MSW4_COM
```

и функциональные профили WB-M1W2:

```text
W1_TEMP
W1_LEAK
W1_GERCON
W2_TEMP
W2_LEAK
W2_GERCON
```

Также ранее существовал диагностический `TEST_TEST`.

Точные рабочие JSON этих профилей на момент реорганизации **не находились ни в GitHub, ни среди доступных исходных файлов**. Их нельзя восстанавливать по памяти или по описанию шаблона: нужно получить точные JSON из рабочего источника / экспорта и затем добавить в эту папку.

До появления точных файлов этот README является явным маркером неполного архива templates и не утверждает, что два сохранённых JSON — весь фактически установленный набор Sprut.hub.
