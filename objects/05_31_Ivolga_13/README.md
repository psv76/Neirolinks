# 05 31 Иволга 13

## Объект

Частный жилой объект **«Иволга 13»**. На участке три строения:

- **Котельная / хозяйственный блок** — основной Wiren Board, ВРУ, инженерные системы;
- **Дом** — два щита автоматики, два шлюза WB-MGE v.3, отдельный Sprut.hub 2;
- **Беседка** — отдельный Wiren Board и Sprut.hub.

Контроллеры, шлюзы и Sprut.hub объединены локальной сетью Ethernet.

## Актуальный статус отопления дома

Статус: **актуализировано 2026-09-09 после проверки на объекте**.

Физика отопления дома отличается от прежних предположений: почти во всех комнатах есть радиаторы. Поэтому прежняя схема с комбо-термостатами отменена, а зональная логика дома переведена на набор simple-термостатов.

Исполняемый скрипт:

**[`Wirenboard/wb-rules/620_thermostats.js`](Wirenboard/wb-rules/620_thermostats.js)**

Канонические документы по отоплению дома:

- **[`HEATING_CHANNEL_MAP.md`](HEATING_CHANNEL_MAP.md)** — актуальная карта отопительных каналов дома;
- **[`THERMOSTAT_MAP.md`](THERMOSTAT_MAP.md)** — актуальная карта simple-термостатов;
- **[`HM2_OWNERSHIP.md`](HM2_OWNERSHIP.md)** — ownership, фактическая гидравлика и порядок адаптации HM2 для Иволги.

Файлы `Wirenboard/wb-webui.conf` и `Wirenboard/wb-mqtt-serial.conf` — конфигурационные снимки объекта в репозитории. Карта отопления от 2026-09-09 составлена по свежим файлам, присланным в рабочий чат: `wb-webui(3).conf` и `wb-mqtt-serial (2).conf`. Если старые общие карты противоречат `HEATING_CHANNEL_MAP.md`, для отопления дома использовать `HEATING_CHANNEL_MAP.md`.

Старые данные от 2026-09-07 по термостатам считать историческими.

## HM2 / ownership котельной

Статус: **добавлено 2026-09-10**.

Для Иволги не проектируется новая архитектура Heating Manager 2.0. Используется уже принятый общий каркас HM2:

```text
consumer → атомарный request → arbiter → source manager → единственный writer источника
```

Объектная особенность Иволги: зональные термостаты реализованы в Wiren Board скриптом `620_thermostats.js`, а не во внешнем Home Assistant.

Общий reusable-регулятор смесительного клапана находится в:

```text
Templates/WB-rules/Heating/HM2/MixingController/
```

Для Иволги он должен использоваться объектными managers смесительных контуров, а не копироваться из Исети вместе с объектными каналами.

Подробная текущая карта ownership: **[`HM2_OWNERSHIP.md`](HM2_OWNERSHIP.md)**.

## Архитектура зональных термостатов

**Wiren Board — владелец логики отопления и физических сервоприводов.**

Sprut.hub используется как пользовательский интерфейс:

- отображение температуры;
- изменение уставки;
- включение / выключение термостата;
- отображение текущего режима.

Физические выходы отопления не должны напрямую управляться сценариями Sprut.hub, если ими уже владеет `620_thermostats.js`.

## Инженерные системы объекта

На объекте автоматизированы:

- отопление;
- наружное освещение;
- часть освещения дома;
- климатические датчики и зональное отопление дома;
- циркуляция ГВС;
- защита от протечек;
- мониторинг электроснабжения;
- освещение и отопление беседки.
