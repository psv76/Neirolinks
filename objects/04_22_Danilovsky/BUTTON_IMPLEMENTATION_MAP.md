## Как читать локальные действия

### WB-MR6C

В текущих модулях используются два основных режима:

- `mode = 0` — кнопка без фиксации, штатное прямое управление одноимённым выходом;
- `mode = 6` — mapping-матрица для кнопок.

Для mapping-матрицы в текущем конфиге:

- `1` — выключить;
- `2` — включить;
- `3` — переключить.

### WB-LED

Числа `inN_sp / inN_lp / inN_dp` декодированы по официальной карте регистров WB-LED.

Используемые на объекте значения:

- `0x3007 = 12295` — переключить CCT1;
- `0x3008 = 12296` — переключить CCT2;
- `0x3009 = 12297` — переключить RGB;
- `0x300A = 12298` — переключить непрерывную смену цвета RGB;
- `0xB010 = 45072` — изменять яркость RGB с чередованием направления;
- `0x900E = 36878` — увеличить Hue;
- `0xB003 = 45059` — изменять значение канала 4 с чередованием направления.

# Что нужно поправить в локальных настройках до новых скриптов

Кандидаты на изменение:

1. **202 / MR203 Input2** — обычную кнопку заменить на mapping: только short → K2 toggle.
2. **212 / MR156 Input0** — проверить текущий режим; не допустить штатного «выключить все выходы», оставить short → OFF только K1.
3. **218 / MR206 Input4** — добавить short → K4 toggle для резервного гр.307.
4. **228 / MR206 Input1** — добавить short → K4 toggle; убрать незадокументированное double → K1.
5. **229 / MR156 Input5** — short изменить с toggle K5 на ON K5.
6. **233 / MR138 Input4** — обычную кнопку заменить на mapping: short → K4 toggle, long без local action.
7. **210 / MR156 Input4** — убрать незадокументированное double → K4, если оно отдельно не подтверждено.
8. **201 long** — привести локальную логику двух WB-LED к требованиям либо отключить её перед JS.
9. **216 short** — отдельно решить конфликт аппаратного дневного поведения с ночным режимом ТЗ.

# Блокеры, которые нельзя решить кодом без решения человека

## 205

Физическая разводка/локальные действия и ТЗ описывают разные группы света.

## 221 / 236

Две физические клавиши замыкают один и тот же `wb-mr6c_138/Input 1`, но ТЗ назначает им разные long-функции.

## 222 / 230

Две клавиши замыкают один `wb-mr6c_206/Input 2`. Short одинаковый и проблем нет, но long 230 автоматически станет доступен и на 222.

# Практический следующий шаг

Перед написанием новых JS:

1. согласовать три блокера выше;
2. внести и сохранить только согласованные изменения mapping-матриц;
3. обновить `wb-mqtt-serial.conf` в объектовой папке;
4. после этого писать скрипты по одному, начиная с функций без открытых вопросов.
