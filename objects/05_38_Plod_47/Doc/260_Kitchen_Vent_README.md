# 260_Kitchen_Vent.js

## Назначение

Скрипт управляет вытяжкой кухни через четыре дискретных входа скорости и аналоговый выход диммирования.

Система для журнала:

```text
[вентиляция][260_Kitchen_Vent][кухня]
```

## Логика

- `wb-mcm8_50/Input 1` → скорость 1 → 25%.
- `wb-mcm8_50/Input 2` → скорость 2 → 50%.
- `wb-mcm8_50/Input 3` → скорость 3 → 75%.
- `wb-mcm8_50/Input 4` → скорость 4 → 100%.
- Если все входы выключены → общеобменная вентиляция 16%.
- Если включено несколько входов → выбирается максимальная скорость.

## Каналы

### Читает

```text
wb-mcm8_50/Input 1
wb-mcm8_50/Input 2
wb-mcm8_50/Input 3
wb-mcm8_50/Input 4
```

### Пишет

```text
A16/Channel 1 Switch
A16/Channel 1 Dimming Level
```

## Логирование

Сделано минимальное логирование:

- загрузка скрипта;
- команда включить канал вытяжки;
- команда установить скорость;
- ошибка недоступности выходного канала;
- отключение сценария флагом `enabled=false`.

Событие “уровень без изменений” больше не пишется в журнал, чтобы не засорять системный журнал.

Пример:

```text
[вентиляция][260_Kitchen_Vent][кухня]; КОМАНДА=Установить скорость вытяжки; причина=изменение входов; входы=S2; цель=50%; канал=A16/Channel 1 Dimming Level; значение в канал=50%
```

## Рефакторинг

- Существующее имя `KITCHEN_HOOD_CFG` сохранено.
- Существующие каналы не переименованы.
- Прямые записи в выходы дополнены проверкой доступности канала.
- Код оставлен в ES5-стиле для `wb-rules`.
