# 290__day_night.js — системный датчик «День / Ночь»

## Назначение

Скрипт создаёт устойчивое состояние дня, ночи и периода вечернего освещения.

Нужен для сценариев, где нельзя полагаться на разовый триггер времени.

Пример: наружное освещение должно работать от заката до 01:00 даже после:

- перезагрузки контроллера;
- пропадания питания;
- перезапуска `wb-rules`;
- временного сбоя связи со Sprut.hub.

## Архитектура

```text
WB = расчёт, состояние, системный журнал
Sprut.hub = отображение и использование готовых признаков
```

Скрипт не включает освещение напрямую. Он только публикует устойчивые признаки:

```text
day_night/is_day
day_night/is_night
day_night/is_evening_light_time
```

Другие скрипты уже могут использовать эти каналы как условия.

## Виртуальное устройство

MQTT device id:

```text
day_night
```

Каналы:

| Канал | Смысл |
|---|---|
| `current_time` | текущее локальное время контроллера |
| `sunrise_time` | расчётное время восхода |
| `sunset_time` | расчётное время заката |
| `state_text` | `День` / `Ночь` / ошибка |
| `is_day` | true от восхода до заката |
| `is_night` | true от заката до восхода |
| `is_evening_light_time` | true от заката до `EVENING_LIGHT_END_TIME` |
| `evening_light_window` | текстовое окно вечернего освещения |
| `calculation_ok` | расчёт выполнен корректно |
| `last_update` | время последнего пересчёта |

## Настройки объекта

В начале файла:

```javascript
var LATITUDE = 56.8389;
var LONGITUDE = 60.6057;
var EVENING_LIGHT_END_TIME = "01:00";
```

`USE_CONTROLLER_TIMEZONE = true` означает, что используется локальное время контроллера.

## Логирование

Система:

```text
освещение
```

Формат журнала:

```text
[освещение][290__day_night][день ночь]; ТИП=событие; параметр=значение
```

События:

```text
СКРИПТ=Скрипт загружен
СКРИПТ=Стартовая инициализация завершена
СОСТОЯНИЕ=Ночь включена
СОСТОЯНИЕ=День включен
ОШИБКА=Ошибка расчёта дня и ночи
АВАРИЯ=Ошибка настройки дня и ночи
```

Переходы дня и ночи пишутся только при смене состояния.

Пример заката:

```text
[освещение][290__day_night][день ночь]; СОСТОЯНИЕ=Ночь включена; причина=текущее время после заката; текущее_время=13.05.2026 21:12; восход=04:38; закат=21:11; вечернее_освещение=да; окно_вечернего_освещения=21:11-01:00
```

Пример восхода:

```text
[освещение][290__day_night][день ночь]; СОСТОЯНИЕ=День включен; причина=случился восход; текущее_время=14.05.2026 04:39; восход=04:38; закат=21:13; вечернее_освещение=нет; окно_вечернего_освещения=21:13-01:00
```

## Проверка в WebUI

В устройстве `День / Ночь` проверить:

```text
Расчёт выполнен = true
Состояние = День / Ночь
Восход = рассчитанное время
Закат = рассчитанное время
Вечернее освещение = true / false
```

В системном журнале:

```text
Сервис = wb-rules
Поиск = 290__day_night
```

или:

```text
Поиск = освещение
```

## Совместимость с регламентом

Скрипт:

- использует ES5: `var`, обычные `function`;
- не использует `let`, `const`, стрелочные функции;
- не использует `isDefined()`;
- не использует `sleep()`;
- не пишет в физические выходы;
- пишет события в системный журнал в принятом формате;
- использует строчные теги в квадратных скобках;
- не создаёт `event_*` каналы.
